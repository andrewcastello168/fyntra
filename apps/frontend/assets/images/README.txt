Fyntra Logo Asset Pack
======================

Recommended Expo mapping:

assets/images/icon.png
  -> App icon (1024x1024)

assets/images/adaptive-icon.png
  -> Android adaptive foreground image (1024x1024, transparent)

assets/images/splash-icon.png
  -> Splash screen symbol (1024x1024, transparent)

assets/images/favicon.png
  -> Web favicon (48x48)

assets/images/notification-icon.png
  -> Android notification glyph (512x512, monochrome white on transparent)

Brand/UI assets:

assets/images/fyntra-wordmark.png
  -> Full Fyntra AI horizontal wordmark

assets/images/fyntra-symbol.png
  -> Standalone Fyntra symbol

assets/images/logo-horizontal.png
  -> Alias of the horizontal wordmark

assets/images/logo-mark.png
  -> Alias of standalone symbol

Note:
- These assets are derived from the previously approved Fyntra AI brand/logo artwork.
- If your Expo project already uses different filenames, either rename these files or update app.json/app.config.ts.
